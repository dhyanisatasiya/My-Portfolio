Display:Flex,Flex-wrap

  • The flex-wrap property specifies wheather the items should wrap or not,if there is not enough room for them on one flex line
  • The flex-wrap property can have one of the following value:
  • nowrap
  • wrap
  • wrap-reverse

Display:Flex,Flex-wrap:no-wrap

  • The nowrap values specifies that the flex items will not wrap
