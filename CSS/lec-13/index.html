Display : Flex (Child Property) Flex - Basis

Display : Flex (Child Property) Flex - Grow

  • The flex-grow CSS property sets the flex grow factor, which specifies how much of the flex container's positive free space should be assigned to the flex item's main size.
  • When the flex container is larger than the combined size of its items, the remaining free space is distributed according to each item's flex-grow value.
Flex-Grow : Auto
Flex-Grow : 1
Flex-Grow : 2

Display : Flex (Child Property) Flex - Shrink

  • The flex-shrink CSS property sets the flex shrink factor of a flex item. If the size of all flex items is larger than the flex container, the flex items can shrink to fit according to their flex-shrink value. Each flex item's negative free space is distributed between the line's flex items that have a flex-shrink value greater than 0.
Flex-Shrink : 0
Flex-Shrink : 1
Flex-Shrink : 2
